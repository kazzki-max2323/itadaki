# いただきタウン

お店を買って、増資して、株でもうける、いたスト風のボードゲームです。あなた 対 CPU 3人。

## あそぶ

**https://kazzki-max2323.github.io/itadaki/**

スマホで開いて「ホーム画面に追加」すると、アプリのように全画面・オフラインで遊べます。

（このURLは GitHub Pages を有効にすると開けるようになります。Settings → Pages → Deploy from a branch → `main` / `/(root)`）

ダウンロードして、ブラウザで `index.html` を開いても遊べます。
## 主なルール

- サイコロで進み、空き店を買う。ほかの人の店に止まったら買い物料をはらう
- 同じエリアの店を集めるほど買い物料が上がる。増資で店の価値を上げる
- エリアの株を買って、株価の上昇と配当でもうける
- ♠♥♦♣ を集めて銀行にもどると昇進して給料
- チャンスボード（8×8、100種類のカード）、競売、交渉、ミニゲーム
- 目標の総資産で銀行にもどったら優勝

## ファイル

- `index.html` … ゲーム本体（1ファイル）
- `manifest.webmanifest`, `icons/` … ホーム画面に追加するためのアプリ情報とアイコン
- `sw.js` … オフラインで遊ぶための仕組み

もとは [my-web-toys](https://github.com/kazzki-max2323/my-web-toys) の `itadaki-town` フォルダで作り、変更の履歴ごとこのリポジトリに移しました。
